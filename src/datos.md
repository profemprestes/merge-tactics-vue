# Merge Tactics GG - Base de Datos

Documentación detallada sobre las tropas y las sinergias (rasgos) extraída de la información oficial de la temporada actual.

## 🛡️ RASGOS: Sinergias de equipo y activaciones

Los **Rasgos (Traits)** determinan las sinergias pasivas que obtiene tu equipo al combinar diferentes tropas en el tablero. Las activaciones dependen de cuántas tropas distintas con el mismo rasgo tengas desplegadas.

| Rasgo | Descripción | Activaciones |
| :--- | :--- | :--- |
| **Ace** | Uno se convierte en Capitán. | `[2] 40% Dmg`<br>`[4] 100% Dmg` |
| **Assassin** | Saltan a la retaguardia enemiga. | `[2] +30% ASPD`<br>`[4] +60% ASPD` |
| **Clan** | Bonus de HP al equipo. | `[2] +30% HP`<br>`[4] +50% HP` |
| **Dragon** | Bonus vs Melee. | `[2] 33% Bonus` |
| **Fire** | Ataques ígneos y velocidad extra. | `[2] Efectos de quemadura` |
| **Goblin** | Genera Goblins extra. | `[2] 2-3 Cost`<br>`[4] 3-4 Cost` |
| **Hinder** | Ralentiza la velocidad enemiga. | `[2] -30% Speed`<br>`[4] -60% Speed` |
| **Marksman** | +1 Rango y daño lejano. | `[2] +30% Dmg`<br>`[4] +60% Dmg` |
| **Noble** | Defensa para adyacentes. | `[2] -10% Dmg`<br>`[4] -25% Dmg`<br>`[6] -60% Dmg` |
| **Superstar**| Recarga de habilidad. | `[2] 50% Recast` |
| **Tank** | Cura rápida bajo 50% HP. | `[2] +40% HP`<br>`[4] +80% HP` |
| **Titan** | Efectos protectores. | `[2] Efecto Activo` |
| **Undead** | Maldice al enemigo con más HP. | `[2] -25% HP`<br>`[4] -50% HP`<br>`[6] -80% HP` |
| **Warrior** | Daño y Atk Speed tras 4s. | `[2] +40%`<br>`[4] +80%` |
